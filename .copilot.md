\admin\.agent
Mano rekomenduojamas frontend stack (Ops admin)

1. Core
   SvelteKit (latest, Svelte 5)
   TypeScript (privalomai strict mode)
   Kodėl: jau turi Svelte kryptį projekte, mažiau kognityvinės apkrovos komandai, labai greitas UI iteravimas.

2. UI komponentai
   Tailwind CSS
   shadcn-svelte (arba Skeleton/kit-style komponentų biblioteka)
   Lucide icons
   Kodėl: greitai sukursit enterprise-like admin UI (lentelės, modalai, drawer, badge, tabs, command palette) be didelio custom CSS.

3. Data layer
   TanStack Query (Svelte adapteris) – server state, cache, invalidation, retries
   Zod – request/response runtime validacija
   openapi-typescript – tipų generavimas iš /api/v1/openapi.json
   Kodėl: labai svarbu ops panelėje turėti patikimą cache/refresh/polling bulk job’ams ir mažiau „rankinių“ tipų klaidų.

4. Formos
   sveltekit-superforms + Zod
   Kodėl: greiti, validuoti action formai (mark-paid, adjust inventory, bulk actions).

5. Lentelės / dideli sąrašai
   @tanstack/table-core su Svelte wrapper
   Virtualization (pvz. @tanstack/virtual-core)
   Kodėl: order/search ekranai su daug eilučių veiks sklandžiau (ypač remote backlog scenarijuje).

6. Datos ir locale
   dayjs arba date-fns
   naudoti backend timezone/locale taisykles pagal shop
7. Auth ir API klientas
   Vienas centralizuotas apiClient su:
   credentials: 'include'
   vienodu error mapping (400/401/403/404/409)
   request timeout + retry tik idempotent GET’ams
   Jokio token laikymo localStorage (jau teisingai pas jus)
